# 프론트엔드 설계 문서

프론트엔드 아키텍처와 개발 규약을 정리한 문서 모음입니다. 비즈니스 도메인 규칙의 원본은 [backend/docs/](../../backend/docs/README.md)에서 관리하며, 이 디렉터리에서는 프론트엔드의 모듈 경계, 실행 환경(서버·브라우저), 공통 처리 흐름을 다룹니다.

## 읽기 순서

| 순서 | 디렉터리                                | 다루는 내용                                 |
| ---- | --------------------------------------- | ------------------------------------------- |
| 1    | [architecture/](architecture/README.md) | 모듈 구조, 렌더링 전략, API 통신, 인증 흐름 |

## 작성 원칙

### 배치 기준

| 판단 기준                                                             | 배치 위치                                     |
| --------------------------------------------------------------------- | --------------------------------------------- |
| 모듈 경계, 렌더링, 서버·클라이언트 간 공통 실행 구조에 관한 규칙인가? | `architecture/`                               |
| 코드 스타일, 린트, 컴파일러, 테스트 도구 설정에 관한 규약인가?        | `conventions/`                                |
| 특정 기능 영역의 복잡한 클라이언트 처리 흐름과 설계 배경인가?         | `design-notes/`                               |
| 기술과 무관한 도메인 불변식이나 컨텍스트 경계 결정인가?               | [backend/docs/](../../backend/docs/README.md) |

### 번호 접두사

앞 문서가 뒤 문서의 전제가 되어 순서대로 읽어야 하는 `architecture/` 디렉터리에만 번호 접두사(`01-`, `02-` 등)를 붙입니다. `conventions/`와 `design-notes/`는 번호 접두사를 사용하지 않습니다.

- 문서 경로를 이동하거나 파일명을 변경할 때는 해당 경로를 참조하는 다른 문서와 코드 주석도 함께 수정합니다.
