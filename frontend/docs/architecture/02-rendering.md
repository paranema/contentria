# 렌더링 전략

검색 엔진 노출(SEO)이 필요한 공개 화면은 서버에서 렌더링하고, 상태 상호작용이 많은 관리·인증 화면은 클라이언트 중심으로 구성합니다.

## 경로별 전략

| 경로                                        | 렌더링 방식                     | 설계 배경                                                                                                       |
| ------------------------------------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `(home)`                                    | SSR                             | 플랫폼 홈과 정책 페이지의 검색 엔진 노출 및 초기 응답 속도를 확보합니다.                                        |
| `/@<블로그주소>`, `/@<블로그주소>/<글주소>` | SSR (`force-dynamic`)           | 공개 블로그와 게시글 본문, 동적 메타데이터(`generateMetadata`)를 서버에서 완성해 검색 엔진에 제공합니다.        |
| `dashboard/*`                               | 서버 레이아웃 + 클라이언트 본문 | 회원·블로그 기본 정보는 서버에서 조회하고, 마크다운 편집·카테고리 정렬·차트 상호작용은 브라우저에서 처리합니다. |
| `(auth)/*`                                  | CSR                             | 이메일 인증 코드 입력, 비밀번호 재설정, reCAPTCHA 전환 등 다단계 폼 상태를 클라이언트에서 관리합니다.           |

공개 게시글 상세 페이지(`PostDetailPage`)는 게시글 본문, 작성자 프로필, 블로그 레이아웃, 첨부 영상, 좋아요·댓글 집계를 서버에서 `Promise.all`로 병렬 조회해 한 번에 렌더링합니다.

## 라우팅 규칙

- **라우트 그룹 분리**: URL 경로에는 영향을 주지 않는 라우트 그룹(`(home)`, `(auth)`, `dashboard/(main)`, `dashboard/(editor)`, `dashboard/(onboarding)`)을 사용해 화면 성격별로 전용 레이아웃을 분리합니다.
- **공개 블로그 경로 리라이트**: 사용자에게 노출되는 `/@<블로그주소>` 형식의 주소는 `next.config.ts`의 `rewrites` 설정을 통해 내부 App Router 경로로 매핑합니다.
  - `/@:blogSlug` → `/user/:blogSlug`
  - `/@:blogSlug/:postSlug` → `/user/:blogSlug/posts/:postSlug`
- **이전 슬러그 영구 리다이렉트**: 게시글 슬러그가 변경된 뒤 과거 주소로 접근하면 백엔드의 이동 응답(`moved`)을 받아 현재 주소로 `308 Permanent Redirect`(`permanentRedirect`)를 수행합니다.
- **한글 슬러그 디코딩**: Next.js 동적 세그먼트는 비 ASCII 문자를 퍼센트 인코딩된 상태로 전달하므로, 페이지 진입 시 한 번 디코딩한 뒤 API 호출 함수에서 일관되게 인코딩합니다.

## 서버 프리페치

로그인 사용자 프로필은 헤더 등 대부분의 화면에서 공통으로 참조합니다. 클라이언트 마운트 이후 추가 요청으로 인해 프로필 영역이 깜빡이는 현상을 막기 위해, 루트 레이아웃(`src/app/layout.tsx`)에서 요청 시점에 내 프로필을 서버 프리페치(`prefetchQuery`)하고 TanStack Query의 `HydrationBoundary`로 클라이언트에 전달합니다.
