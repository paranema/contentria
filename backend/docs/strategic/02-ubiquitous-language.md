# 유비쿼터스 언어

코드, 설계 문서, 팀 내 의사소통에서 동일한 개념을 동일한 단어로 표현하기 위한 용어집입니다. 영문 표기는 코드 네이밍의 기준 어휘가 되며, 독립된 도메인 개념(모델·상태 타입)은 `PascalCase`, 속성·역할·행위는 `camelCase`로 표기합니다. 새로운 도메인 개념이 필요한 경우 이 문서에 먼저 등재합니다.

## 컨텍스트별 용어

각 바운디드 컨텍스트 내부에서 사용하는 핵심 도메인 용어입니다.

### 회원 (`member`)

회원의 가입, 인증, 프로필 관리에 사용하는 용어입니다.

| 용어      | 영문 표기       | 의미                                                                                                                                  |
| --------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 회원      | `Member`        | 플랫폼에 가입을 완료한 사용자입니다. 내부적으로 '계정'과 '프로필'로 구성됩니다.                                                       |
| 계정      | `Account`       | 인증과 로그인의 주체입니다. 이메일, 계정 상태, 권한, 자격증명을 보유하며 본인만 조회할 수 있습니다.                                   |
| 자격증명  | `Credential`    | 계정의 신원을 증명하는 수단입니다 (비밀번호 해시 또는 소셜 로그인 공급자 식별 정보).                                                  |
| 계정 상태 | `AccountStatus` | 활성(`ACTIVE`), 정지(`SUSPENDED`), 탈퇴(`WITHDRAWN`) 상태를 가집니다. 정지 및 탈퇴 상태에서는 로그인과 게시글·댓글 작성이 제한됩니다. |
| 프로필    | `Profile`       | 다른 사용자에게 공개되는 표시 이름과 프로필 사진입니다. 블로그별이 아닌 회원당 하나만 존재합니다.                                     |
| 표시 이름 | `displayName`   | 화면에 노출되는 회원의 이름입니다. 플랫폼 전체에서 중복될 수 없습니다.                                                                |

### 출판 (`publishing`)

블로그 운영과 카테고리 구성, 게시글 작성·발행에 사용하는 용어입니다.

| 용어          | 영문 표기    | 의미                                                                                                                        |
| ------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 블로그        | `Blog`       | 회원이 개설한 게시글의 공간입니다. 슬러그(`slug`)로 식별되는 고유한 공개 주소를 가집니다.                                   |
| 블로그 소유자 | `owner`      | 블로그를 개설한 회원입니다. 블로그당 소유자는 한 명입니다.                                                                  |
| 작성자        | `author`     | 게시글이 속한 블로그의 소유자입니다. 1인 블로그 전제를 따르므로 게시글에 별도 저장하지 않고 블로그 소유자로부터 도출합니다. |
| 슬러그        | `slug`       | URL 경로에 사용되는 식별 문자열입니다. 블로그 슬러그는 플랫폼 전체에서, 게시글 슬러그는 해당 블로그 내에서 유일합니다.      |
| 카테고리      | `Category`   | 블로그 내 게시글을 묶는 분류 체계입니다. 상위(부모)·하위(자식) 계층 구조를 가질 수 있습니다.                                |
| 글 (게시글)   | `Post`       | 블로그에 작성되는 마크다운 기반의 문서입니다.                                                                               |
| 글 상태       | `PostStatus` | 임시저장, 발행, 비공개, 보관 상태를 가집니다.                                                                               |
| 발행          | `publish`    | 작성한 글을 독자에게 공개되는 상태로 전환하는 행위입니다.                                                                   |
| 샘플          | `sample`     | 블로그를 처음 개설할 때 함께 자동 생성되는 예시 카테고리와 예시 게시글입니다.                                               |

### 상호작용 (`interaction`)

독자가 블로그를 구독하고 게시글에 댓글과 좋아요를 남길 때 사용하는 용어입니다.

| 용어        | 영문 표기      | 의미                                                                                                  |
| ----------- | -------------- | ----------------------------------------------------------------------------------------------------- |
| 구독        | `Subscription` | 회원이 특정 블로그의 새 글 소식을 받기 위해 맺는 관계입니다. 구독 대상은 회원이 아닌 블로그입니다.    |
| 구독자      | `subscriber`   | 특정 블로그를 구독한 회원입니다.                                                                      |
| 댓글        | `Comment`      | 로그인한 회원이 게시글에 남기는 의견입니다.                                                           |
| 댓글 작성자 | `commenter`    | 댓글을 작성한 회원입니다. 게시글의 '작성자(`author`)'와 명확히 구분합니다.                            |
| 좋아요      | `Like`         | 회원이 게시글에 남기는 공감 표시입니다. 한 게시글에 회원당 한 번만 남길 수 있으며 취소할 수 있습니다. |
| 좋아요 수   | `likeCount`    | 게시글에 누적된 좋아요 개수입니다. 출판이 아닌 상호작용 컨텍스트가 소유합니다.                        |

### 미디어 (`media`)

게시글에 포함되는 이미지와 영상 파일의 업로드·변환·정리에 사용하는 용어입니다.

| 용어        | 영문 표기     | 의미                                                                                                                          |
| ----------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 미디어      | `Media`       | 게시글 본문 안에 삽입되는 이미지 파일입니다.                                                                                  |
| 영상        | `Video`       | 게시글에 첨부되는 동영상 파일입니다. 게시글당 하나의 활성 영상만 첨부할 수 있습니다.                                          |
| 첨부 (연결) | `attach`      | 업로드된 이미지(`Media`)나 영상(`Video`)을 특정 게시글과 연결하는 처리입니다.                                                 |
| 업로드 중   | `uploading`   | Presigned URL이 발급되었으나 아직 업로드 완료 및 서버 검증을 마치지 않은 이미지 상태입니다.                                   |
| 업로드 완료 | `complete`    | 스토리지에 업로드된 파일의 형식을 검증하고 본문에서 사용할 수 있는 상태로 확정하는 처리입니다 (파일 URL은 변경되지 않습니다). |
| 정리        | `cleanup`     | 업로드가 완료되지 않은 임시 파일이나 어느 게시글에서도 참조하지 않는 미사용 미디어를 삭제하는 작업입니다.                     |
| 영상 변환   | `transcode`   | 업로드된 원본 영상을 HLS 적응형 스트리밍 포맷으로 인코딩하는 처리입니다.                                                      |
| 영상 상태   | `VideoStatus` | 대기, 변환 중, 완료, 실패, 삭제 상태를 가집니다.                                                                              |

### 분석 (`analytics`)

독자의 방문 기록 수집과 트래픽 통계 산출에 사용하는 용어입니다.

| 용어      | 영문 표기         | 의미                                                                                                                              |
| --------- | ----------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 방문      | `Visit`           | 독자가 블로그나 게시글을 열람한 개별 기록입니다.                                                                                  |
| 조회수    | `viewCount`       | 중복 방지 규칙(동일 독자의 30분 이내 재방문 제외)을 통과한 유효 방문 수입니다. 게시글의 속성이 아니며 분석 컨텍스트가 소유합니다. |
| 방문자 수 | `visitorCount`    | 하루 동안 방문한 고유 독자(순방문자)의 수입니다.                                                                                  |
| 일별 통계 | `DailyStatistics` | 하루 단위로 집계한 블로그별·게시글별 방문자 수와 조회수 데이터입니다.                                                             |
| 인기 글   | `popularPost`     | 특정 기간 동안 조회수가 높은 순서로 선정된 게시글입니다.                                                                          |

### 알림 (`notification`)

도메인 이벤트에 따른 회원 알림 전달에 사용하는 용어입니다.

| 용어   | 영문 표기      | 의미                                                                                    |
| ------ | -------------- | --------------------------------------------------------------------------------------- |
| 알림   | `Notification` | 다른 컨텍스트에서 발생한 주요 도메인 이벤트를 회원에게 전달하기 위해 생성한 내역입니다. |
| 수신자 | `recipient`    | 알림을 전달받는 대상 회원입니다.                                                        |

## 용어 사용 규칙

### 컨텍스트 외부 용어

특정 컨텍스트 하나에 귀속되지 않고 여러 컨텍스트의 결과를 조합하는 화면이나 운영 주체를 가리키는 용어입니다.

| 용어            | 의미                                                                |
| --------------- | ------------------------------------------------------------------- |
| 관리자          | 플랫폼 전체를 운영하는 관리 주체입니다 (개별 블로그 소유자와 구분). |
| 블로그 대시보드 | 블로거가 자신의 블로그 통계와 현황을 확인하는 화면입니다.           |
| 관리자 대시보드 | 플랫폼 관리자가 전체 서비스 현황을 확인하는 화면입니다.             |

### 지양하는 표현

의미가 모호하거나 도메인 전제와 어긋나서 사용하지 않는 표현과 대체 용어입니다.

| 지양 표현       | 대체 규칙                                                                                                                                                                                                                                         |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 사용자 (`user`) | 도메인 모델 이름으로 사용하지 않습니다. 레거시에서는 `User` 하나로 계정, 프로필, 블로그 소유자, 글 작성자를 모두 표현해 책임이 모호했습니다. 신규 구조에서는 문맥에 맞게 **회원, 계정, 프로필, 소유자, 작성자, 독자**로 명확히 구분해 사용합니다. |
| 블로그 관리자   | 사용하지 않습니다. 블로그 소유자인지 플랫폼 운영 관리자인지 모호하므로 **블로그 소유자** 또는 **관리자**로 구분합니다.                                                                                                                            |
| 대시보드        | 단독으로 쓰지 않고 **블로그 대시보드**인지 **관리자 대시보드**인지 명시합니다.                                                                                                                                                                    |
| 조회            | 독자의 게시글 열람(조회수)과 데이터베이스 조회(Query)가 혼동될 수 있으므로, 열람 횟수를 뜻할 때는 반드시 **조회수**라고 표기합니다.                                                                                                               |
| 팔로우          | 사용하지 않습니다. 관계의 대상이 사람(회원)이 아니라 블로그이므로 **구독**으로 통일합니다.                                                                                                                                                        |
| 닉네임          | 사용하지 않고 **표시 이름(`displayName`)**으로 통일합니다.                                                                                                                                                                                        |
