# 유비쿼터스 언어

코드, 문서, 대화에서 같은 단어를 같은 뜻으로 쓰기 위한 용어집이다.
코드 이름은 이 표를 따른다. 표에 없는 개념이 필요하면 이 문서에 먼저 추가한다.

## 회원

| 용어 | 코드 이름 | 뜻 |
|---|---|---|
| 회원 | Member | 가입을 마친 사람. 계정과 프로필로 이루어진다 |
| 계정 | Account | 로그인의 주체. 이메일, 상태, 권한, 자격증명을 가진다. 본인만 읽는다 |
| 자격증명 | Credential | 계정을 증명하는 수단. 비밀번호 또는 소셜 공급자 신원 |
| 계정 상태 | AccountStatus | 활성, 정지, 탈퇴. 정지와 탈퇴 상태에서는 로그인과 글·댓글 작성이 불가능하다 |
| 프로필 | Profile | 다른 사람에게 보이는 이름과 사진. 회원당 하나다. 블로그마다 두지 않는다 |
| 표시 이름 | displayName | 프로필의 이름. 플랫폼 안에서 중복될 수 없다 |

## 출판

| 용어 | 코드 이름 | 뜻 |
|---|---|---|
| 블로그 | Blog | 회원이 소유한 글의 묶음. 슬러그로 식별하는 공개 주소를 가진다 |
| 블로그 소유자 | owner | 블로그를 만든 회원. 블로그당 한 명이다 |
| 작성자 | author | 글이 속한 블로그의 소유자. 1인 블로그이므로 글에 따로 저장하지 않고 블로그에서 유도한다 |
| 슬러그 | slug | URL에 쓰는 식별 문자열. 블로그 슬러그는 플랫폼 안에서, 글 슬러그는 블로그 안에서 유일하다 |
| 카테고리 | Category | 블로그 안의 글 분류. 부모와 자식을 가질 수 있다 |
| 글 | Post | 블로그에 속한 마크다운 문서 |
| 글 상태 | PostStatus | 임시저장, 발행, 비공개, 보관 |
| 발행 | publish | 글을 독자가 볼 수 있는 상태로 바꾸는 것 |
| 샘플 | sample | 블로그를 만들 때 함께 생성되는 예시 카테고리와 예시 글 |

## 상호작용

| 용어 | 코드 이름 | 뜻 |
|---|---|---|
| 구독 | Subscription | 회원이 블로그를 구독하는 관계. 대상은 사람이 아니라 블로그다 |
| 구독자 | subscriber | 블로그를 구독한 회원 |
| 댓글 | Comment | 로그인한 회원이 글에 남기는 글 |
| 댓글 작성자 | commenter | 댓글을 쓴 회원. 글의 "작성자"와 구분한다 |
| 좋아요 | Like | 회원이 글에 남기는 표시. 한 글에 한 번이고 취소할 수 있다 |
| 좋아요 수 | likeCount | 한 글에 남은 좋아요의 수. 상호작용이 소유한다 |

## 미디어

| 용어 | 코드 이름 | 뜻 |
|---|---|---|
| 미디어 | Media | 글 본문에 들어가는 이미지 파일 |
| 영상 | Video | 글에 첨부하는 영상 파일. 글 하나에 활성 영상은 하나다 |
| 첨부 | attach | 미디어나 영상을 글에 연결하는 것 |
| 임시 업로드 | temporary | 업로드 직후 아직 글에 연결되지 않은 상태 |
| 승격 | promote | 글을 저장할 때 임시 업로드를 영구 위치로 옮기는 것 |
| 영상 변환 | transcode | 원본 영상을 스트리밍 형식으로 바꾸는 처리 |
| 영상 상태 | VideoStatus | 대기, 변환 중, 완료, 실패, 삭제 |

## 분석

| 용어 | 코드 이름 | 뜻 |
|---|---|---|
| 방문 | Visit | 독자가 블로그나 글을 연 기록 한 건 |
| 조회수 | viewCount | 중복 제거 규칙을 거친 방문의 수. 같은 독자가 30분 안에 다시 연 것은 세지 않는다. 분석이 소유하며 글의 속성이 아니다 |
| 방문자 수 | visitorCount | 하루 동안 서로 다른 독자의 수 |
| 일별 통계 | DailyStatistics | 하루 단위로 집계한 블로그별, 글별 방문자 수와 조회수 |
| 인기 글 | popular post | 기간 안의 조회수가 많은 순으로 고른 글 |

## 컨텍스트 밖

| 용어 | 뜻 |
|---|---|
| 관리자 | 플랫폼 운영자. 블로그 소유자와 다르다 |
| 블로그 대시보드 | 블로거가 자기 블로그의 통계를 보는 화면 |
| 관리자 대시보드 | 관리자가 플랫폼 전체를 보는 화면 |

## 혼동하기 쉬운 말

| 말 | 규칙 |
|---|---|
| 사용자, user | 도메인 이름으로 쓰지 않는다. 레거시는 `User` 하나로 계정, 프로필, 블로그 소유자, 작성자를 모두 표현했다. 새 코드는 회원, 계정, 프로필, 소유자, 작성자, 독자 중 무엇인지 고른다 |
| 블로그 관리자 | 쓰지 않는다. 블로그 소유자인지 플랫폼 관리자인지 구분되지 않는다 |
| 대시보드 | 단독으로 쓰지 않는다. 블로그 대시보드인지 관리자 대시보드인지 붙인다 |
| 조회 | 독자의 글 조회(조회수)와 데이터 조회(query)가 섞인다. 조회수를 말할 때는 "조회수"라고 쓴다 |
| 팔로우 | 쓰지 않는다. 구독 대상이 사람이 아니라 블로그이기 때문이다 |
| 닉네임 | 쓰지 않는다. 표시 이름으로 통일한다 |

## 레거시 이름 대응

| 레거시 | 새 이름 | 비고 |
|---|---|---|
| User | Account + Profile | 계정 정보와 공개 정보를 나눈다 |
| User.nickname | Profile.displayName | |
| User.username, User.realUsername | 정하지 않음 | 표시 이름 외에 이름을 더 둘지는 회원 컨텍스트에서 정한다 |
| Blog.userId | Blog.ownerId | |
| Post.authorId | 없음 | 블로그 소유자에서 유도한다 |
| Post.viewCount | 분석의 조회수 | |
| Post.likeCount | 상호작용의 좋아요 수 | |
