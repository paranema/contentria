# 도메인 개요

## 제품 소개

Contentria는 회원이 자신만의 블로그를 개설하고 글을 발행하는 블로그 플랫폼입니다.
독자는 발행된 글을 읽고, 관심 있는 블로그를 구독하며, 게시글에 댓글과 좋아요를 남길 수 있습니다.

## 도메인 전제 조건

바운디드 컨텍스트의 경계를 판단하는 기준이 되는 제품 수준의 전제 조건입니다. 이 전제가 바뀌면 [03-bounded-contexts.md](03-bounded-contexts.md)와 [04-context-map.md](04-context-map.md)의 설계를 재검토해야 합니다.

| #   | 전제 조건                                                                                  | 도메인 설계에 미치는 영향                                                     |
| --- | ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| 1   | 블로그는 1인 소유 구조이며, 다중 작성자(팀 블로그) 지원 계획은 없습니다.                   | 게시글의 작성자는 항상 해당 블로그의 소유자와 일치합니다.                     |
| 2   | 한 회원이 여러 개의 블로그를 개설할 수 있습니다.                                           | 작성자의 표시 이름과 프로필 사진은 블로그가 아닌 회원에 귀속됩니다.           |
| 3   | 구독의 대상은 회원이 아니라 개별 블로그입니다.                                             | 동일 회원이 운영하는 다른 블로그는 각각 별도로 구독합니다.                    |
| 4   | 댓글은 로그인한 회원만 작성할 수 있습니다.                                                 | 모든 댓글 작성자는 회원 식별자로 식별됩니다.                                  |
| 5   | 블로그 소유자가 타인의 댓글을 삭제하거나 숨기는 중재 기능은 현재 범위에 포함하지 않습니다. | 상호작용 컨텍스트가 출판 컨텍스트로부터 알아야 하는 정보 범위가 단순해집니다. |
| 6   | 관리자는 모든 블로거를 통합 관리하는 플랫폼 운영자입니다.                                  | 개별 블로그를 운영하는 블로그 소유자와는 구분되는 별도의 행위자입니다.        |
| 7   | 신고 처리나 제재 이력 관리 같은 별도의 운영 정책은 현재 범위에 포함하지 않습니다.          | 별도의 운영(Moderation) 컨텍스트를 두지 않습니다.                             |

## 행위자 (Actor)

블로거와 독자는 별도의 계정 유형이 아니라, 동일한 회원이 상황에 따라 수행하는 역할입니다.

| 행위자          | 정의                                                                                                                  |
| --------------- | --------------------------------------------------------------------------------------------------------------------- |
| 블로거          | 하나 이상의 블로그를 소유하고 운영하는 회원                                                                           |
| 독자 (비로그인) | 로그인하지 않은 상태로 공개된 블로그와 글을 읽는 사용자                                                               |
| 독자 (로그인)   | 로그인한 상태로 글을 읽고 구독, 댓글, 좋아요 활동을 하는 회원                                                         |
| 관리자          | 플랫폼 전체 현황을 모니터링하고 관리하는 운영자                                                                       |
| 시스템          | 스케줄러나 메시지 큐 이벤트에 의해 자동으로 실행되는 백그라운드 처리 주체 (영상 변환, 미사용 파일 정리, 통계 집계 등) |

## 주요 유스케이스

| 상태 | 의미                                                                             |
| ---- | -------------------------------------------------------------------------------- |
| 현재 | 현재 아키텍처에 구현되어 있는 기능                                               |
| 계획 | 담당 컨텍스트는 확정되었으나 아직 구현하지 않은 기능                             |
| 보류 | 레거시에는 존재했으나 현재 구조에서는 범위에서 제외한 기능 (추후 필요 시 재검토) |

| 행위자          | 유스케이스                                                               | 상태 | 담당 컨텍스트                  |
| --------------- | ------------------------------------------------------------------------ | ---- | ------------------------------ |
| 블로거          | 회원가입, 이메일 인증, 비밀번호 로그인, 인증 코드 로그인, 소셜 로그인    | 현재 | 회원                           |
|                 | 비밀번호 재설정                                                          | 현재 | 회원                           |
|                 | 표시 이름 변경                                                           | 현재 | 회원                           |
|                 | 계정 설정 (소셜 로그인 연동·해제, 비밀번호 변경, 이메일 변경, 회원 탈퇴) | 현재 | 회원                           |
|                 | 블로그 개설 (기본 샘플 카테고리 및 샘플 게시글 자동 생성 포함)           | 현재 | 출판                           |
|                 | 블로그 설정 수정 (제목, 소개글)                                          | 현재 | 출판                           |
|                 | 카테고리 트리 구성 및 변경                                               | 현재 | 출판                           |
|                 | 게시글 작성, 수정, 삭제                                                  | 현재 | 출판                           |
|                 | 이미지 및 영상 업로드                                                    | 현재 | 미디어                         |
|                 | 블로그 대시보드 조회 (방문자 수, 조회수, 인기 게시글)                    | 현재 | 분석 + 출판 (조회 조합)        |
| 독자 (비로그인) | 블로그 홈, 게시글 목록, 게시글 상세, 최근 게시글 조회                    | 현재 | 출판                           |
|                 | 댓글 목록, 좋아요 수, 구독자 수 조회                                     | 현재 | 상호작용                       |
|                 | 방문 기록 적재                                                           | 현재 | 분석                           |
| 독자 (로그인)   | 블로그 구독, 구독 해지, 내 구독 목록 조회                                | 현재 | 상호작용                       |
|                 | 댓글 및 답글 작성, 수정, 삭제                                            | 현재 | 상호작용                       |
|                 | 게시글 좋아요, 좋아요 취소, 좋아요한 게시글 목록 조회                    | 현재 | 상호작용                       |
|                 | 알림 수신 및 읽음 처리                                                   | 현재 | 알림                           |
| 관리자          | 전체 블로거 목록 조회, 관리자 대시보드 조회                              | 계획 | 회원 + 출판 + 분석 (조회 조합) |
| 시스템          | 업로드된 원본 영상의 HLS 스트리밍 변환                                   | 현재 | 미디어                         |
|                 | 미완료 업로드 이미지 및 삭제된 영상 파일 정리                            | 현재 | 미디어                         |
|                 | 일 단위 방문 통계 집계                                                   | 현재 | 분석                           |
|                 | 만료된 인증 토큰 및 인증 시도 이력 정리                                  | 보류 | 회원                           |
|                 | 보존 기간이 만료된 오래된 알림 정리                                      | 현재 | 알림                           |

## 서브도메인 분류

| 서브도메인 | 분류              | 분류 근거                                                                                                                                          |
| ---------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 출판       | 핵심 (Core)       | 플랫폼이 존재하는 핵심 목적이며, 글을 작성하고 발행하는 경험이 서비스의 주요 차별점이 됩니다.                                                      |
| 상호작용   | 지원 (Supporting) | 블로그 플랫폼의 보편적인 기능이지만, 구독과 알림 연동 등 서비스 특성에 맞춘 도메인 규칙이 필요합니다.                                              |
| 미디어     | 지원 (Supporting) | 직접 업로드, 이미지 메타데이터 정제, 영상 변환 파이프라인을 자체 구현했으나 비즈니스 차별점 자체는 아니며 외부 관리형 서비스로 대체할 수 있습니다. |
| 분석       | 지원 (Supporting) | 블로그 대시보드와 관리자 대시보드에 필요한 통계 지표를 산출하여 제공합니다.                                                                        |
| 회원       | 일반 (Generic)    | 회원가입, 인증, 프로필 관리는 대부분의 웹 서비스에서 공통으로 요구되는 기능입니다.                                                                 |
| 알림       | 일반 (Generic)    | 알림 생성 및 발송 내역 관리는 도메인 특수성이 낮은 범용 기능입니다.                                                                                |

### 서브도메인 분류에 따른 설계 지침

| 분류              | 설계 및 구현 지침                                                                                   |
| ----------------- | --------------------------------------------------------------------------------------------------- |
| 핵심 (Core)       | 도메인 모델링에 가장 높은 우선순위를 두며, 비즈니스 불변식과 규칙을 애그리거트 내부에 응집시킵니다. |
| 지원 (Supporting) | 요구사항을 충족하는 수준으로 간결하게 모델링하고 단순한 구조에서 출발합니다.                        |
| 일반 (Generic)    | 업계 표준 방식을 따르며, 검증된 오픈소스 라이브러리나 외부 서비스 도입을 우선 검토합니다.           |

> **참고**: '일반(Generic) 서브도메인'이라는 분류는 비즈니스 차별화 요소가 아니라는 의미일 뿐, 품질이나 보안을 타협해도 된다는 뜻은 아닙니다. 특히 회원 컨텍스트의 인증 규칙은 보안과 직결되므로 [contexts/member/01-rules.md](../contexts/member/01-rules.md)에서 별도로 엄격하게 정의합니다.
