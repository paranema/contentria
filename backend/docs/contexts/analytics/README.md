# analytics 컨텍스트 (분석)

독자의 방문을 기록하여 조회수와 방문자 수를 집계하고, 블로그 대시보드에 통계 지표를 제공하는 지원(Supporting) 서브도메인입니다.

| 애그리거트        | 내부 구성 요소 | 공개 범위                                                                  |
| ----------------- | -------------- | -------------------------------------------------------------------------- |
| `Visit`           | 없음           | 비공개 — 원본 방문 기록은 외부에 노출하지 않으며 통계 집계에만 사용합니다. |
| `DailyStatistics` | 없음           | 블로그 통계는 블로그 소유자만 조회, 개별 게시글의 누적 조회수는 전체 공개  |

- **내부 아키텍처**: 레이어드
  - 쓰기 작업은 방문 기록 단건 추가(`INSERT`)뿐이고 나머지 로직은 대부분 SQL 집계 쿼리 중심이므로 4계층 레이어드 아키텍처를 적용합니다.
- **모듈 위치**: `backend/contexts/analytics/` (`analytics-api`, `analytics-core`)
- **실행 프로세스**: 실시간 방문 기록 수집과 대시보드·조회수 쿼리는 `apps/api`에서 처리하며, 일별 통계 집계와 90일 경과 원본 방문 기록 정리는 `apps/batch`에서 수행합니다.
